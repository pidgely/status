# Pidgely status

Uptime monitoring and the public status page for [Pidgely](https://pidgely.com), published at **https://status.pidgely.com**.

Powered by [Upptime](https://github.com/upptime/upptime): GitHub Actions check each endpoint every 5 minutes, incidents become issues in this repository and the status website is built to GitHub Pages.
